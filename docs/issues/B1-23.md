## 목적

학생의 문의와 구매 요청을 받고 관리자가 답합니다(기획안 11장).

## 참고 명세

- [기획안 11장 관리자](../design/기획안.md)
- [openapi.yaml](../api/openapi.yaml) 공지·문의 묶음

## 만들 API

| 방법 | 주소 | 하는 일 | 권한 |
|---|---|---|---|
| POST | `/api/v1/inquiries` | 문의 쓰기 | 학생 |
| GET | `/api/v1/inquiries/me` | 내 문의 | 학생 |
| GET | `/api/v1/admin/inquiries` | 문의 목록 | 관리자 |
| POST | `/api/v1/admin/inquiries/{id}/answer` | 문의 답변 | 관리자 |
| POST | `/api/v1/purchase-requests` | 구매 요청 쓰기 | 학생 |
| GET | `/api/v1/purchase-requests/me` | 내 구매 요청 | 학생 |
| GET | `/api/v1/admin/purchase-requests` | 구매 요청 목록 | 관리자 |
| POST | `/api/v1/admin/purchase-requests/{id}/answer` | 구매 요청 답변 | 관리자 |

요청·응답 칸과 오류 코드는 [openapi.yaml](../api/openapi.yaml)의 같은 주소를 봅니다.

## 범위

- 답변 알림은 `RESPONSE`, 연결 대상은 `INQUIRY` 또는 `PURCHASE_REQUEST`와 해당 id입니다. 같은 숫자 id여도 종류로 구분합니다(B2-13).

- 문의·구매 요청 쓰기, 내 목록, 관리자 목록·답변. 답변하면 학생에게 알림, 새 요청은 관리자에게 `REQUEST` 알림.
