## 만들 API

| 방법 | 주소 | 하는 일 | 권한 |
|---|---|---|---|
| POST | `/api/v1/recommendations` | AI 기자재 추천 | 로그인한 사용자 |

요청·응답 칸과 오류 코드는 [openapi.yaml](../api/openapi.yaml)의 같은 주소를 봅니다.

## 범위

- **첫 작업:** Google AI Studio 프로젝트에서 무료로 사용할 모델을 확인해 `AI_MODEL_ID`를 정하고 실제 호출로 검증합니다. 모델 ID·무료 등급·한도·확인 날짜를 외부 연결 3절에 기록합니다. 유료 전환은 별도 승인 없이 하지 않습니다.
- Google Gemini API 공식 Java SDK 또는 REST API를 사용합니다. Spring 설정으로 읽은 `GEMINI_API_KEY`·`AI_MODEL_ID`를 클라이언트에 전달합니다. 활성화 시 두 값이 비어 있으면 설정 오류를 알리고 비밀값은 출력하지 않습니다.
- 무료 한도 초과도 `AI_UNAVAILABLE`로 처리하고 유료 모델로 자동 전환하지 않습니다. 요청에는 기자재 목록과 사용 목적만 넣고 계정 개인정보는 넣지 않습니다.
- 요청에 우리 모델 목록과 목적을 넣고 JSON으로 답하게 함. 없는 modelId는 버림. 대여 가능 여부는 넣지 않음.
- 시간 초과(20초)·키 오류·한도·JSON 아님은 `503 AI_UNAVAILABLE`, 자동 재시도 없음.
- `recommendation_logs` 기록. `AI_ENABLED=false`면 간단한 대체 추천.

## 서버 구현 후 확인할 것

서버를 만든 뒤 아래 입력을 넣었을 때 예상 결과가 나와야 합니다. 사례 ID가 적힌 행은 [fixtures/cases.json](../../fixtures/cases.json)에 정확한 입력과 결과가 있습니다. 시각 의존 서버 시험은 `Clock`으로 고정합니다. 실제 환경 확인은 실행 시각·환경·결과를 기록합니다.

| # | 입력·상황 | 예상 결과 |
|---|---|---|
| 1 | 실제 키로 한 번 호출 | 모델 ID 확인 결과를 외부 연결 3절에 기록 |
| 2 | 가짜 응답 `{"items":[{"modelId":48,...},{"modelId":9999,...}]}` | 48만 돌려줌 |
| 3 | 사용 목적 201자 | 400 `VALIDATION_ERROR` |
| 4 | 가짜 호출이 시간 초과·키 오류·JSON 아님 | 503 `AI_UNAVAILABLE`, 다시 부르지 않음 |
| 5 | 정상 호출 한 번 | `recommendation_logs` 1행 |
| 6 | `AI_ENABLED=false` | 대체 추천 결과, 로그에 대체 표시 |
| 7 | 제공자가 무료 한도 초과(429)를 응답 | 503 `AI_UNAVAILABLE`, 자동 재시도·유료 모델 전환 없음 |
| 8 | 제공자에게 전달할 요청 검사 | 기자재 목록·사용 목적만 포함, 계정 이름·학번·이메일·학생증·대여 이력 없음 |
