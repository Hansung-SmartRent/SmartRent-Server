## 범위

- 승인된 학생만, 정지 중이면 거절. 컨트롤러 메서드에 `@RequireApprovedStudent`를 붙이면 `NOT_APPROVED`·`SUSPENDED`로 막힙니다(B1-04).
- 모델 행을 잠근 뒤 칸마다 대수를 다시 셈. 하나라도 모자라면 전체 거절(`NO_CAPACITY`).
- 같은 종류(같은 모델 또는 같은 이름) 진행 중 신청이 있으면 `SAME_KIND_ACTIVE`.
- 쉬는 날은 `CLOSED_DAY`, 운영 시간 밖이나 칸 경계 불일치는 `SLOT_INVALID`, 이미 시작한 칸이나 기간 밖은 `OUT_OF_BOOKING_WINDOW`.
- 일반·2일 이상 대여는 `modelId + segments`, 장기 대여는 `modelId + pickupDate`만 받습니다. 두 형식을 섞지 않습니다. 장기 시작은 수령일 운영 시작 시각, 반납 기한은 기획안 4장으로 서버가 계산하며 클라이언트의 종료 시각을 받지 않습니다. 오늘 수령일의 운영 종료가 지났으면 `OUT_OF_BOOKING_WINDOW`; 장기에는 이미 시작한 일반 시간 칸 제한을 적용하지 않습니다.
- `BOOKING` 알림(B2-13).
