## 만들 API

| 방법 | 주소 | 하는 일 | 권한 |
|---|---|---|---|
| GET | `/api/v1/users/me/notification-settings` | 알림 설정 보기 | 로그인한 사용자 |
| PUT | `/api/v1/users/me/notification-settings` | 알림 설정 바꾸기 | 로그인한 사용자 |

요청·응답 칸과 오류 코드는 [openapi.yaml](../api/openapi.yaml)의 같은 주소를 봅니다.

## 범위

- 설정 보기·바꾸기. 끌 수 있는 것은 반납 전 알림뿐, 나머지는 바꾸려 하면 거절 또는 무시(명세대로).
- 꺼져 있으면 판정 작업이 푸시 없이 알림함만 남김.
