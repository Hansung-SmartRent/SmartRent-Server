## 목적

## 참고 명세

- [기획안 11장 관리자](../design/기획안.md)
- [openapi.yaml](../api/openapi.yaml) 공지·문의 묶음

## 만들 API

| 방법 | 주소 | 하는 일 | 권한 |
|---|---|---|---|
| GET | `/api/v1/notices` | 공지 목록 | 로그인한 사용자 |
| POST | `/api/v1/admin/notices` | 공지 쓰기 | 관리자 |
| PUT | `/api/v1/admin/notices/{id}` | 공지 수정 | 관리자 |
| DELETE | `/api/v1/admin/notices/{id}` | 공지 삭제 | 관리자 |

요청·응답 칸과 오류 코드는 [openapi.yaml](../api/openapi.yaml)의 같은 주소를 봅니다.

## 범위

- 공지 목록(학생), 쓰기·수정·삭제(관리자). 새 공지는 학생에게 `NOTICE` 알림(B2-13, 푸시 여부는 명세대로).

## 제외

- 문의·구매 요청(B1-23)
