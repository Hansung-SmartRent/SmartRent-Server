# [FEAT] B2-17 탈퇴·재가입 경고 보관

## 목적

탈퇴한 학생의 경고를 학번과 함께 6개월 보관하고, 같은 학번으로 돌아오면 되살립니다(기획안 1장).

## 참고 명세

- [기획안 1장 계정](../design/기획안.md)
- [DB 설계 3절 retained_warnings, 4절 탈퇴 시 경고](../db/README.md)
- 확인 사례: `AUTH-03` 대여 중이면 탈퇴를 거부하고, 아니면 예약을 취소하고 경고를 6개월 보관한다 ([fixtures/cases.json](../../fixtures/cases.json))

## 범위

- `retained_warnings` 엔티티. 탈퇴할 때 유효 경고를 옮김(`retain_until` = 탈퇴 + 6개월).
- 같은 학번으로 재가입해 [B1-15](B1-15.md)에서 승인될 때 복원 서비스를 호출합니다. 학생증 제출 때는 복원하지 않습니다. 원래 정지 종료 시각이 미래이면 그 시각을 그대로 복원하고 새로 6개월을 부과하지 않습니다. 이미 정지가 끝났으면 해당 경고를 만료 처리하고 정지를 되살리지 않습니다. 보관 기한이 끝난 기록은 복원하지 않습니다. 같은 승인 처리를 반복해도 중복 경고를 만들지 않습니다.
- 관리 기록의 학번은 6개월 뒤 "탈퇴 회원"으로(판정 작업 [B2-10](B2-10.md)에서 호출).
