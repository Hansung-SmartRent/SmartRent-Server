## 범위

- [DB 설계 7절 판정 작업](../db/README.md)대로 한 번 실행이 끝난 뒤 1분 간격(`fixedDelay = 60000`)으로 실행. 판정 대상만 골라 처리하고, 같은 일을 두 번 하지 않게 표시 칸을 먼저 저장.
- 판정은 실행 시각이 아니라 마감 시각과 비교하고, 경고·노쇼·취소 기록의 시각은 마감 시각으로 저장. 서버가 꺼져 있던 동안 밀린 것은 켜진 뒤 첫 실행에서 모두 처리.
- 예약 시작 판정: 예약 시작 시각에 같은 모델의 다른 정상 기기로도 내줄 수 없으면 해당 예약을 즉시 CANCELLED로 처리하고 CANCEL 알림을 보냅니다. 학생에게 경고를 주지 않습니다. 이후 기기가 반납돼도 취소된 예약을 되살리거나 수령 안내를 보내지 않습니다. 시작 판정은 노쇼보다 먼저 적용합니다. 기기가 있어 유지된 일반·2일 이상 예약만 시작 + 10분 미수령 시 NO_SHOW, 장기는 수령일 운영 종료 시 미수령이면 NO_SHOW입니다. 노쇼일 때만 기존 규칙대로 같은 신청의 남은 칸 취소·신청 단위 경고 1회를 적용합니다.
- 시작 판정 지연 시에도 시작 시점 기준으로 판단합니다. 10:00에 기기가 없었고 10:20에 반납됐으면 10:21에 판정하더라도 예약은 기기 부족 취소이며 노쇼가 아닙니다. 수령·반납 요청의 선행 시작 판정과 같은 함수를 사용합니다.
- 연체 경고 `LATE`, 반납 전 알림(장기 7일·2일 이상 1일·하루 15분 전), 정지 해제, 보관 삭제(B2-17).
- 실행 시각은 `Clock`에서. 시험에서는 판정 함수를 직접 부름.
