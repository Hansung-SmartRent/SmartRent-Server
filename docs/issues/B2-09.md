## 범위

- 연장 선택지: 하루 대여는 그날 운영 종료까지, 2일 이상 대여는 다음 주 금요일까지 운영일만. 다음 예약과 겹치지 않게(반출 1시간 여유).
- 연장하기: 한 번만, 기한 전에만, 모델 행 잠금. 장기는 `LONG_TERM_EXTENSION_BLOCKED`. 정지 중이면 `SUSPENDED`(컨트롤러에 `@RequireApprovedStudent`, B1-04).
- 반납 전 알림 표시(`due_notified`)를 지워 새 기한 기준으로 다시 알림.
- 2일 이상 대여 시험은 예시 모델 `demo-lg`(기획안 4장)로. 예시 모델도 실제 모델과 똑같이 동작해야 함.
