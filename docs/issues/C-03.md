## 목적

문서에 "추천"으로 적은 값을 팀이 정해, 구현할 때 값을 짐작해 만들지 않게 합니다. 결정은 따로 모으지 않고 그 값이 적힌 문서에 바로 "확정"으로 고칩니다.

## 범위

- `grep -rn "추천" docs`로 추천값을 모두 찾아 하나씩 정합니다. 그대로 쓰면 "확정"으로, 바꾸면 값을 고치고 "확정"으로.
- 자주 쓰는 추천값: 비밀번호 8자 이상, 토큰 30분·14일, 사진 jpg·png 10MB 이하, 임시 주소 10분, AI 응답 시간 초과 20초, 공휴일 받기 매일 새벽 4시, 목록 쪽 크기 20.
- 값이 바뀌어 규칙 결과가 달라지면 [CONVENTION 5절](../CONVENTION.md#5-규칙이-바뀔-때-함께-맞출-것)대로 DB·API 문서, 확인 사례, 이슈를 함께 고칩니다.

- 통계의 집계 기준일·건수 단위·취소/만료 경고 처리: API README 통계 추천안과 B1-24 확인 표를 함께 검토합니다. 확인 전 집계 구현에 착수하지 않습니다.
- 파일 삭제 재시도 간격, 운영 DB 생성 방식 등 내부 기술 선택은 담당 이슈 착수 계획에서 확인하고 해당 명세에 반영합니다.
