## 만들 API

| 방법 | 주소 | 하는 일 | 권한 |
|---|---|---|---|
| POST | `/api/v1/auth/login` | 로그인 | 없음 |
| POST | `/api/v1/auth/token/refresh` | 토큰 새로 받기 | 없음 |
| POST | `/api/v1/auth/logout` | 로그아웃 | 로그인한 사용자 |

요청·응답 칸과 오류 코드는 [openapi.yaml](../api/openapi.yaml)의 같은 주소를 봅니다.

## 범위

- Spring Security + JWT: 로그인하면 access·refresh 토큰 발급, `POST /auth/token/refresh`로 새로 받기. 기간은 `.env`(확정: 30분·14일).
- 권한: 없음 / 로그인한 사용자 / 학생 / 관리자. 승인 전 학생·정지 학생이 부를 수 없는 API 처리는 API 명세 1-5절대로.
- 로그인 잠금: 5번 연속 틀리면 5분 막음, 성공하면 기록 삭제(기획안 1장).
- 리프레시 토큰은 `refresh_tokens`에 해시로 저장. 로그아웃(`POST /auth/logout`)하면 그 토큰과, 보낸 경우 그 휴대폰의 푸시 토큰을 지움(DB 설계 3절).
- 로그인 응답에 승인 상태·정지 여부를 넣어 앱이 알맞은 화면으로 보냄(openapi.yaml 스키마대로).
