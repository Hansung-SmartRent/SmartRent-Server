## 범위

- `application.yml`에 `spring.config.import: "optional:file:.env[.properties]"`를 넣어 프로젝트 루트의 `.env`를 properties 형식으로 읽습니다. IntelliJ와 bootRun의 작업 폴더를 프로젝트 루트로 맞추며, 별도 dotenv 라이브러리나 각자 IDE에 비밀값을 중복 입력하는 방식을 요구하지 않습니다.
- `.env.example`의 대문자 키는 OS 환경변수와 달리 파일 속성으로 읽히므로 실제 Spring 설정에 명시적으로 연결합니다. 예: `server.port: ${SERVER_PORT:8080}`, `spring.profiles.active: ${SPRING_PROFILES_ACTIVE:local}`. DB 항목 매핑은 B1-02에서 완성합니다. 시간대는 기존 Clock·JVM 설정으로 보장합니다.
- 테스트는 개인 `.env` 없이 실행할 수 있는 별도 설정을 제공하고, 개인 DB·메일·AI로 연결되지 않게 합니다. `optional`은 파일 부재만 허용하며 필수값 누락까지 허용하는 뜻이 아닙니다.

- Spring Initializr로 Gradle 프로젝트 생성: Java 21, 패키지 `kr.ac.hansung.smartrent`(추천), 의존성 Web·Validation·Data JPA·MySQL Driver·Security·Lombok(선택)·springdoc-openapi.
- Spring Boot 버전은 생성 시점의 최신 안정판 중 springdoc-openapi가 지원하는 것으로 정하고 README 기술 스택에 적습니다.
- 공통 응답 `ApiResponse<T>{success, message, data, errorCode}`와 성공·실패 만드는 함수.
- 오류 코드 `ErrorCode` enum: [API 명세 오류 코드 전체](../api/README.md) 52개를 이름·HTTP 상태 그대로. 전역 예외 처리(`@RestControllerAdvice`)로 검증 오류는 `VALIDATION_ERROR`, 처리하지 못한 예외는 `INTERNAL_ERROR`.
- `Clock` 빈(`Asia/Seoul`)과 JVM 기본 시간대 설정. 스케줄러 사용 설정(`@EnableScheduling`)만 켜 둠.
- Swagger 화면이 `/swagger-ui/index.html`에서 열리도록 설정(보안 설정에서 열어 둠).
- `application.yml`은 환경변수(`.env.example`의 이름)로 값을 읽게 하고, `local`/`prod` 프로필을 나눔.
- 헬스 체크용 `GET /api/v1/health` 하나(명세 밖, 배포 확인용).
- (팀 결정으로 B1-02에서 당겨옴) `docker-compose.yml`의 `mysql:9.7` 서비스와 `spring.datasource`에 `DB_URL`·`DB_USERNAME`·`DB_PASSWORD` 연결. 서버는 개발 DB에 연결해 켜집니다. 필수값이 비면 이름을 알리고 멈춥니다.
- 시험은 개인 DB 대신 Testcontainers로 띄운 MySQL 9.7에 연결합니다(Docker 필요).
