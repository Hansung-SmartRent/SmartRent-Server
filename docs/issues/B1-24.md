## 목적

관리자가 기간별 대여 현황과 누가 무엇을 고쳤는지 봅니다(기획안 11장).

## 참고 명세

- [기획안 11장 관리자](../design/기획안.md)
- [openapi.yaml](../api/openapi.yaml) 통계·기록 묶음

## 만들 API

| 방법 | 주소 | 하는 일 | 권한 |
|---|---|---|---|
| GET | `/api/v1/admin/stats` | 이용 통계 | 관리자 |
| GET | `/api/v1/admin/audit-logs` | 관리 기록 | 관리자 |

요청·응답 칸과 오류 코드는 [openapi.yaml](../api/openapi.yaml)의 같은 주소를 봅니다.

## 범위

- 통계: from·to 기간을 받아 대여·반납·노쇼·연체 수와 많이 빌린 모델을 반환합니다. 집계 기준일·단위는 API README 통계 집계 기준(C-03 확정)대로 구현합니다. 상태별 전체 현황은 별도 필드로 구분합니다.
- 관리 기록: `audit_logs` 목록, from·to 기간·action 또는 actions 필터. 필터를 먼저 적용한 뒤 페이지 처리. actions의 화면 묶음은 API README 기준입니다.

## 제외

- 기록 남기기(각 기능에서 함)
