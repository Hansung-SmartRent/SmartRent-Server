## 목적

창구에서 쓰는 관리자 첫 화면과 대여 현황 목록입니다.

## 참고 명세

- [기획안 11장 관리자](../design/기획안.md)
- [openapi.yaml](../api/openapi.yaml) 관리자 대여 묶음

## 만들 API

| 방법 | 주소 | 하는 일 | 권한 |
|---|---|---|---|
| GET | `/api/v1/admin/summary` | 관리자 홈 숫자와 우선 처리 | 관리자 |
| GET | `/api/v1/admin/rentals` | 대여 현황 | 관리자 |

요청·응답 칸과 오류 코드는 [openapi.yaml](../api/openapi.yaml)의 같은 주소를 봅니다.

## 범위

- 홈: 오늘 수령 예정, 대여 중, 연체, 가입 대기 수와 우선 처리 목록(명세대로).
- 대여 현황: 상태 필터와 이름·학번·모델 이름·배정 기기 코드 검색, 쪽 나누기(openapi.yaml의 조회 조건 기준). 앱이 몇 초마다 새로 부르므로 가볍게(필요한 칸만, 인덱스 확인).

- 관리자 대여 목록 검색은 이름·학번·모델 이름뿐 아니라 배정된 기기 코드도 지원합니다. 관리자 대여 상세에도 Rental의 신고 내용·반납 판정·파손 처리 시각이 포함되는지 확인합니다.
