## 만들 API

| 방법 | 주소 | 하는 일 | 권한 |
|---|---|---|---|
| GET | `/api/v1/rentals/me` | 내 대여 목록 | 학생 |
| GET | `/api/v1/rentals/{id}` | 대여 상세 | 로그인한 사용자 |

요청·응답 칸과 오류 코드는 [openapi.yaml](../api/openapi.yaml)의 같은 주소를 봅니다.

## 범위

- 대여 응답에는 신고 내용(brokenNote), 반납 상태(returnCondition), 반납 후 파손 처리 시각(damageDiscoveredAt)을 포함합니다. 관리자도 같은 대여 필드를 받습니다. 미발생 값은 null로 반환하고 학생은 자신의 대여만 조회합니다.

- 진행 중(예약·대여 중)과 지난 기록을 나눠 보여 줌. 같은 신청의 칸은 묶어서(명세대로).
- 상세: 상태, 기한, 받은 기기, 연장 가능 여부, 취소 가능 여부.
- 관리자는 모든 대여 상세를 볼 수 있음.
