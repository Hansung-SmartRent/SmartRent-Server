## 목적

휴대폰이 사진으로 인식한 모델명을 받아 기자재 모델 하나를 돌려줍니다. 앱은 그 모델의 상세 화면으로 이동합니다. 서버는 사진을 받지 않습니다.

## 참고 명세

- [기획안 10장 스캔과 AI 추천](../design/기획안.md)
- [API 명세 3절 기자재](../api/README.md)

## 만들 API

| 방법 | 주소 | 하는 일 | 권한 |
|---|---|---|---|
| POST | `/api/v1/models/recognition` | 사진 인식 결과로 찾기 | 로그인한 사용자 |

요청·응답 칸과 오류 코드는 [openapi.yaml](../api/openapi.yaml)의 같은 주소를 봅니다.

## 범위

- 요청 `modelName`을 모델 이름과 비교: 대소문자와 공백을 무시하고 같으면 일치. 운영 종료 모델은 제외.
- 일치하면 모델 요약(id 포함)을 돌려줌. 앱은 이 id로 `GET /models/{id}` 상세 화면을 엶.
- 일치하는 모델이 없으면 `404 NOT_FOUND`. 앱은 찾지 못했다는 안내를 띄움(그다음 QR·바코드로 넘어가는 것은 앱의 일, 기획안 10장).
- 기기 한 대 단위로 찾지 않음. 기기 코드로 찾기는 [B1-11](B1-11.md).

## 제외

- 휴대폰의 인식 기능
- 서버에서 사진 인식
- 여러 후보 목록 돌려주기
